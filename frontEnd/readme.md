# ココカラ 画面仕様書

## 1. 概要

本画面は、ユーザーの1日の生活状況（食事・睡眠・歩数・体調）を  
**日付およびカレンダーとともに可視化するライフログ表示画面**である。

HTMLおよびCSSのみを用いた静的Webページとして実装されており、  
JavaScriptなどの動的処理は行わない。

---

## 2. 使用技術

- HTML5  
- CSS3  
- レイアウト方式  
  - Flexbox  
  - Grid Layout  

※ 外部ライブラリ、JavaScriptは使用しない。

---

## 3. ファイル構成
project/
├── index.html   画面構造を定義
└── style.css    画面デザインを定義

---

## 4. 画面全体仕様

| 項目 | 内容 |
|---|---|
| 画面幅 | 1100px（固定） |
| 背景色 | 外側：黒（#111）<br>内側：白（#fff） |
| フォント | 日本語ゴシック体 |
| 表示形式 | PC表示前提 |

---

## 5. 画面構成

画面は以下の3エリアで構成される。

1. 上部エリア（ヘッダー）
2. 左側エリア（カレンダー）
3. 右側エリア（ライフログカード）

---

## 6. 上部エリア（ヘッダー）

### 6.1 構成要素

- アプリタイトル
- メモ入力欄

### 6.2 仕様

| 項目 | 内容 |
|---|---|
| タイトル | 固定表示「ココカラ」 |
| メモ欄 | 任意文字入力可能（保存機能なし） |
| 配置 | 横並び（Flexbox） |

---

## 7. 左側エリア（カレンダー）

### 7.1 日付表示

| 項目 | 内容 |
|---|---|
| 表示内容 | 2026/05/06（水） |
| 表示形式 | YYYY/MM/DD（曜日） |
| 役割 | 現在選択されている日付を示す |

---

### 7.2 月間カレンダー

#### 構成
- `table` 要素による月間カレンダー
- 曜日行 + 日付マスで構成

#### 仕様

| 項目 | 内容 |
|---|---|
| 表示単位 | 月表示（2026年5月） |
| 曜日 | 日〜土 |
| 当日表示 | `class="today"` を付与し背景色を変更 |
| 動的処理 | なし（固定表示） |

---

## 8. 右側エリア（ライフログカード）

右側は **2列 × 2行** のカードレイアウトで表示する。

### 8.1 共通カード仕様

| 項目 | 内容 |
|---|---|
| 形状 | 角丸矩形 |
| 配置 | CSS Grid |
| 影 | 下方向に影あり |
| タイトル | 各カード上部に表示 |

---

### 8.2 食事カード

| 項目 | 内容 |
|---|---|
| 表示内容 | 朝・昼・晩 |
| 状態 | 済 / 未 |
| 配色 | 黄色 |

---

### 8.3 睡眠カード

| 項目 | 内容 |
|---|---|
| 表示内容 | 睡眠時間 |
| 表示形式 | 「7時間31分」 |
| 配色 | 青色 |

---

### 8.4 歩数カード

| 項目 | 内容 |
|---|---|
| 表示内容 | 歩数 |
| 表示形式 | 「576歩」 |
| 配色 | 赤色 |

---

### 8.5 体調カード

| 項目 | 内容 |
|---|---|
| 表示方法 | 顔アイコン |
| 実装方法 | div要素のみで構成 |
| 構成 | 目×2、口×1 |
| 配色 | 緑色 |

---

## 9. クラス設計方針

| クラス名 | 役割 |
|---|---|
| `.app` | 画面全体 |
| `.top` | ヘッダー |
| `.main` | メイン領域 |
| `.left` | カレンダーエリア |
| `.right` | カードエリア |
| `.card` | カード共通 |
| `.today` | 当日強調表示 |

---

## 10. 制限事項

- 日付・カレンダーは固定表示
- 入力内容は保存されない
- スマートフォン対応は行わない
- JavaScriptは使用しない
